# bash-php

Õpime kuidas teha apache2 veebileht localhostis, ja vastavalt tegevusele veebilehel käivitame scripti.
Eesmärk on luua hetkel php veebileht kus on tesktikast, sinna tekstikasti sisse kirjutades, läheb input tekstifaili meie bash scripti abil.
Alustame lihtsast ülesandest: laeme alla apache2 ja php.
Seejärel teeme apache2 veebilehele lihtsa text insertion boxi.
